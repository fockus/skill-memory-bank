## Deviations

- Filenames now use the canonical v2 form `<date>_<hhmm>_<sid8>.md` instead of `_pi_<sid8>`. The shared `mb-session-recent-rebuild.sh` and the catch-up exclusion only recognize the canonical form, so Pi sessions had never reached `_recent.md`. A resume still finds older `_pi_` files only if their sid8 suffix matches; legacy `_pi_` files are not migrated. Bats test 11's glob was updated.
- Capture lives in the skill bundle. If the skill dir lacks `adapters/pi_native_session.mjs`, capture is disabled and a notice is shown. Bats test 4 no longer expects capture from a broken skill dir.
- The pre-compaction record is written as a `## Handoff capsule` section with bullets (kept for bats compatibility), not inside the Live log.

## Risks / follow-ups

- If a user later sets `MB_SUMMARY_BACKEND`/`MB_SUMMARIZE_BIN` globally, the Claude Code catch-up can add an LLM `## Summary` after an existing deterministic one, because `summarized` stays false by design. Recent rebuild would then concatenate both.
- When an LLM summarizer is explicitly configured, Pi waits on it at shutdown for up to `MB_SESSION_LLM_TIMEOUT` (default 30 s here, versus 240 s for Claude Code). A killed summarizer can leave `session/.lock` until its 300 s TTL.
- Redaction spawns one bash per user input (5 s bound). If redaction fails, the text is replaced with `[redaction unavailable]` and the raw text is never written.
- One global write chain: a slow summarizer delays other runtimes in the same process (`ponytail:` note in code).
